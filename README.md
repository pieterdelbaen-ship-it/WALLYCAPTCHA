# 🤖 Google reCAPTCHA - Waar is Wally? (Grap / Prank)

## Waarom heb ik dit gemaakt? / Why did I make this?
Iedereen heeft een bloedhekel aan reCAPTCHA-beveiligingen. Je klikt op stoplichten of zebrapaden, en de helft van de tijd keurt het systeem het fout. Daarom leek het mij een fantastisch idee om deze frustratie om te zetten in iets leuks!

Dit project is een **ludieke reCAPTCHA-grap** speciaal gemaakt voor iemand die me lief is. 

---

### Hoe de grap werkt / How the prank works:
1. Het slachtoffer denkt een normale beveiliging in te vullen.
2. Er klapt een onmogelijke "Waar is Wally?"-zoekplaat uit.
3. De eerste keer geeft het systeem direct een harde foutmelding: *"Systemen tonen aan dat u een robot bent!"*
4. Wanneer ze het verward nog een keer proberen, klapt de puzzel dicht en verschijnt de echte boodschap: 

> **"Robot of geen robot, ik hou nog steeds van jou! ❤️"**
